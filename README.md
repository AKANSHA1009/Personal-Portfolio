# Akansha Sharma | Portfolio

My personal portfolio site. I'm a Quality Engineer working on test automation, and I'm building toward AI-integrated testing. This is where I keep my experience, projects and what I'm learning.

Built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Run it locally

Clone the repo and open `index.html` in your browser. That's it.

```bash
git clone https://github.com/AKANSHA1009/Personal-Portfolio.git
cd Personal-Portfolio
open index.html
```

## What's in it

- Hero, About, Experience, Skills, Projects, Learning and Contact sections
- Light and dark theme that follows your system setting and remembers your choice
- Filters for skills and projects
- Scroll animations and a subtle animated background, both turned off if you have reduced motion enabled
- Mobile-friendly layout with keyboard navigation and a skip link
- Contact form that opens a draft in your email app (there's no backend)

## Project structure

```
index.html    page content and metadata
style.css     styles, theme colours and layout
script.js     theme toggle, navigation, filters, animations
assets/       portrait, favicon, icons and resume PDF
```

## Deploying on GitHub Pages

1. Push the repo to GitHub.
2. Go to Settings > Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, then save.
3. Once the site is live, add your URL to the canonical link and `og:url` tag in the `<head>` of `index.html`.
